# EMG FAQ (ওয়ার্ডপ্রেস প্লাগইন)

**ভার্সন:** `emg-faq.php` ফাইলের হেডারে উল্লেখিত (বর্তমানে 1.1.2)

ফ্রন্টএন্ডে FAQ **শুধু তখনই** দেখাবে যখন আপনি **শর্টকোড** ব্যবহার করবেন। গ্লোবাল সেটিংস **WP Admin → EMG FAQ** মেনুতে। JSON-LD স্কিমা **ফুটারে** প্রিন্ট হয়; CSS সাধারণত **হেডে** একবার লোড হয় (মেইন পোস্ট কনটেন্টে শর্টকোড থাকলে আগে থেকেই, নয়তো শর্টকোড চালু হওয়ার সময়)।

---

## ইনস্টলেশন

1. `EMG-FAQ` ফোল্ডারটি `wp-content/plugins/` এ কপি করুন।
2. **প্লাগইনস** থেকে **EMG FAQ** অ্যাক্টিভ করুন।
3. অ্যাডমিন সাইডবারে **EMG FAQ** মেনুতে গিয়ে সেটিংস সেভ করুন।

---

## অ্যাডমিন: **EMG FAQ** অপশনসমূহ

| অপশন | কাজ |
|--------|-----|
| **Default FAQ (Global)** | যখন শর্টকোডের **ভেতরে কোনো কনটেন্ট নেই** (শুধু খোলা/বন্ধ ট্যাগ বা ফাঁকা) তখন এটা ব্যবহার হয়। প্রতি লাইনে একটি FAQ: `প্রশ্ন \|\| উত্তর`। |
| **Use custom default FAQ schema (JSON-LD)** | **চেক করা:** নিচের স্কিমা টেক্সট এরিয়া **দেখাবে** এবং সেভ করা JSON **ভ্যালিড** হলে স্কিমা হিসেবে **প্রাধান্য** পাবে (নিচের [স্কিমা টেবিল](#স্কিমা-আচরণ-কেস-অনুযায়ী) দেখুন)। **আনচেক:** এরিয়া লুকানো থাকে; স্ট্রাকচার্ড FAQ এর জন্য **অটো FAQPage** স্কিমা সম্ভব। |
| **Default FAQ Schema (Global JSON-LD)** | শুধু উপরের চেকবক্স **চেক** থাকলে দেখা যায়। **শুধু JSON** পেস্ট করুন (`<script>` ট্যাগ দিয়ে পুরো ব্লক পেস্ট করলে প্লাগইন বাইরের `<script>` কেটে শুধু JSON রাখে)। `city="…"` থাকলে `{{city}}`, `{City}`, `{city}` রিপ্লেস হয়। |
| **FAQ Display Mode** | গ্লোবাল ডিফল্ট লেআউট: **Accordion** (খুলতে ক্লিক) বা **Plain** (প্রশ্ন+উত্তর সরাসরি)। শর্টকোডে `mode="…"` দিলে **ওই ইনস্ট্যান্সে** ওটাই জিতবে। |

### সিটি প্লেসহোল্ডার (ডিফল্ট টেক্সট + গ্লোবাল স্কিমা স্ট্রিং)

`city="Houston"` দিলে:

- আগে `{{city}}` রিপ্লেস (ভেতরে `{city}` আগে রিপ্লেস করলে `{{city}}` ভেঙে যেতে পারে—প্লাগইন সেই অনুসারে অর্ডার মেনে চলে)।
- `{City}` → সিটি নাম।
- `{city}` → সিটি নাম।

`city` **না** দিলে প্লেসহোল্ডার **যেমন আছে তেমন** থাকবে।

## শর্টকোড নাম

দুটো একই কাজ করে:

- `[emg_faq …]…[/emg_faq]`
- `[emg-faq …]…[/emg-faq]`

**বন্ধ করতে হবে `[/emg_faq]` বা `[/emg-faq]` দিয়ে।**  
শেষে আবার `[emg_faq]` দিলে এটা **বন্ধ হয় না**, নতুন শর্টকোড খুলে যাবে।

---

## শর্টকোড অ্যাট্রিবিউট

| অ্যাট্রিবিউট | লাগবে কি | মান / নোট |
|--------------|-----------|-----------|
| `city` | না | সিটি নাম; কনটেন্ট ও গ্লোবাল স্কিমা স্ট্রিং এ প্লেসহোল্ডার রিপ্লেস। |
| `mode` | না | `plain` বা `accordion`। গ্লোবাল **FAQ Display Mode** ওভাররাইড। ভুল মান হলে `accordion`। |
| `class` | না | `<section class="emg-faq-box …">` এ এক্সট্রা ক্লাস। একাধিক: `class="foo bar"`। |
| `title` | না | উপরে `<h2 class="emg-faq-title">`। `city` থাকলে টাইটেলেও প্লেসহোল্ডার রিপ্লেস। |

### উদাহরণ

```text
[emg_faq city="Dallas" mode="plain" class="city-faq" title="Dallas FAQs"]
```

```text
[emg_faq city="Dallas" mode="accordion" class="accordion-faq"]
[/emg_faq]
```

(ভেতর ফাঁকা → **গ্লোবাল** `প্রশ্ন || উত্তর` লাইন ব্যবহার।)

## ভেতরের কনটেন্ট: ৩ ধরনের কেস

### কেস ১ — **ভেতর ফাঁকা** (সেটিংসের ডিফল্ট লিস্ট)

**কখন:** খোলার পর সরাসরি বন্ধ, বা শুধু whitespace।

```text
[emg_faq city="Dallas" mode="accordion"]
[/emg_faq]
```

**আউটপুট:** **Default FAQ (Global)** থেকে `প্রশ্ন || উত্তর` পার্স।  
**লেআউট:** শর্টকোডের `mode`, না থাকলে গ্লোবাল **FAQ Display Mode**।  
**স্কিমা:** নিচের টেবিল।

---

### কেস ২ — **স্ট্রাকচার্ড HTML** (`<h3>` প্রশ্ন + উত্তর ব্লক)

**কখন:** ভেতরে অন্তত একটি `<h3>…</h3>` এবং পরের অংশ পরের `<h3>` বা শর্টকোড শেষ পর্যন্ত।

```text
[emg_faq city="Dallas" mode="plain"]
<h3>{{city}} তে সেবা কী?</h3>
<p>উত্তরের প্যারা…</p>
[/emg_faq]
```

**আউটপুট:** **শুধু ভেতরের কনটেন্ট**; গ্লোবাল লাইন লিস্ট **এই ব্লকের জন্য ব্যবহার হয় না**। প্রশ্নে HTML স্ট্রিপ, উত্তরে নিরাপদ HTML (`wp_kses_post`)।  
**স্কিমা:** আইটেম থাকলে অটো `FAQPage` **অথবা** চেক করা গ্লোবাল ম্যানুয়াল JSON—নিচের টেবিল।  
**সতর্কতা:** ম্যানুয়াল স্কিমা **চেক + ভ্যালিড JSON** থাকলে স্কিমা **গ্লোবাল JSON** থেকে আসে, এই ব্লকের Q&A দিয়ে আবার বানায় না। পেজে দেখা প্রশ্ন আর স্কিমা **মিল না** থাকলে SEO রিস্ক—ম্যানুয়াল JSON আপডেট করুন বা ম্যানুয়াল বন্ধ করে অটো ব্যবহার করুন।

---

### কেস ৩ — **ফ্রি ফরম** (`<h3>` জোড়া মেলে না)

**কখন:** ভেতরে টেক্সট/HTML আছে কিন্তু `<h3>` প্যাটার্নে FAQ সPLIT হয় না।

```text
[emg_faq city="Dallas" mode="plain"]
প্রথম লাইন {{city}}
দ্বিতীয় লাইন
[/emg_faq]
```

**আউটপুট:** `.emg-faq-freeform-body` এর ভেতরে; `city` রিপ্লেস + `wp_kses_post`। ব্লক-লেভেল ট্যাগ (`p`, `div`, `h1–h6` ইত্যাদি) না থাকলে **wpautop** দিয়ে `<p>` তৈরি।  
**স্কিমা:** এই ধরনের ব্লক থেকে **অটো FAQPage হয় না**। শুধু **ম্যানুয়াল স্কিমা চেক + ভ্যালিড গ্লোবাল JSON** থাকলে সেই JSON (একই স্ট্রিং, `city` রিপ্লেস সহ) কিউ হতে পারে।

## স্কিমা আচরণ (কেস অনুযায়ী)

প্রতিটি শর্টকোড ইনস্ট্যান্স যা আসলে HTML আউটপুট দেয়:

| ম্যানুয়াল স্কিমা চেক? | সেটিংসে গ্লোবাল JSON | স্ট্রাকচার্ড Q&A আইটেম আছে? | ফলাফল (JSON-LD) |
|-------------------------|----------------------|------------------------------|------------------|
| না | — | হ্যাঁ | **অটো FAQPage** — ওই ইনস্ট্যান্সের আইটেম থেকে। |
| না | — | না (ফ্রি ফরম) | **কিছু না** (ফ্রি ফরমে অটো FAQPage নেই)। |
| হ্যাঁ | ভ্যালিড + খালি না | যেকোনো | **গ্লোবাল ম্যানুয়াল JSON** (`city` রিপ্লেস)। দৃশ্যমান Q&A দিয়ে পুনর্নির্মাণ নয়। |
| হ্যাঁ | ফাঁকা বা ইনভ্যালিড | হ্যাঁ | **ফলব্যাক:** ওই ইনস্ট্যান্স থেকে **অটো FAQPage**। |
| হ্যাঁ | ফাঁকা বা ইনভ্যালিড | না (ফ্রি ফরম) | **কিছু না** (পরে ভ্যালিড JSON সেভ করলে তখন যাবে)। |

**ডুপ্লিকেট:** একই JSON স্ট্রিং একাধিকবার এলে একবারই `<script type="application/ld+json">` প্রিন্ট (ডিডুপ)।

**কোথায় প্রিন্ট:** `wp_footer` (priority `1`) — Google এর জন্য গ্রহণযোগ্য।

## ফ্রন্টএন্ড অ্যাসেট

- **CSS:** হ্যান্ডেল `emg-faq-frontend`, একবার ইনলাইন। সিঙ্গুলার পোস্টের কনটেন্টে শর্টকোড থাকলে সাধারণত **হেডে**। উইজেট/বিশেষ কনটেক্সটে পরে লোড হতে পারে।
- **Accordion JS:** যেকোনো ইনস্ট্যান্সে `mode="accordion"` (আর আইটেম থাকলে) হলে `#emg-faq-accordion` **একবার** `wp_footer` এ (priority `5`)।

**Shortcode** ব্লকে পুরো শর্টকোড পেস্ট করুন, **`[/emg_faq]` সহ**।

## সমস্যা সমাধান

| সমস্যা | সম্ভাব্য কারণ |
|--------|----------------|
| কিছুই দেখা যায় না | গ্লোবাল FAQ ফাঁকা + ভেতরও ফাঁকা; বা কনটেন্ট ভুল। |
| ভেতরের লেখা আসে না | বন্ধ ট্যাগ `[emg_faq]` দিয়ে দিয়েছেন, `[/emg_faq]` নয়। |
| স্কিমা নেই | ফ্রি ফরম + ম্যানুয়াল বন্ধ; বা ম্যানুয়াল চালু কিন্তু JSON খালি/ভুল; বা অটোর জন্য কোনো Q&A নেই। |
| স্কিমা আর পেজের FAQ মিলে না | ম্যানুয়াল চেক + পুরনো/ভিন্ন গ্লোবাল JSON। |
| `{{city}}` থেকে যায় | `city="…"` শর্টকোডে নেই। |
